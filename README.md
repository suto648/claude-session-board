# Claude セッション盤面

**Claude Code の会話を一覧で見て、ピン留めして、続きから開き直すための盤面。**

会話が増えると「あの作業、どのセッションだったか」が分からなくなります。
この盤面は、手元の会話ログを読んで一覧にし、名前を付けて並べ、
選んだものを元の作業フォルダで開き直します。

Windows 10 / 11 用。画面は日本語です。

---

## 入れかた

1. [Releases](../../releases) から zip を落とす
2. フォルダごと好きな場所に展開する
3. **`claude-session-boardを起動.cmd`** をダブルクリックする

**入れるものはありません。** Node.js は中に入っています。
アンインストールはフォルダを消すだけです。

初回起動時、Windows が「発行元が不明」として一度止めます（署名を付けていないため）。
`詳細情報` → `実行` で通ります。

---

## できること

- 手元の会話ログを読んで、プロジェクト・日付・大きさで並べる
- よく使うものをピン留めし、名前とグループを付ける
- 選んだ会話を、**元の作業フォルダで開き直す**（Windows Terminal のタブとして）
- 複数アカウントの使用量を見る（登録・削除・並べ替えができる）
- セッション内でアカウントが入れ替わったことを検知して知らせる

## 読むだけです

会話ログは**読むだけ**で、書き換えません。
盤面が持つのはピン留めと表示設定（`board.json`）だけです。

資格情報は盤面の中だけで使い、画面にもログにも出しません。

---

## CbC Tools に繋ぐ

[CbC Tools](https://github.com/suto648/cbc-tools) は、自作の常駐ツールを
1つの窓から見て操作するためのハブです。この盤面は**その繋ぎ方の実装例**にもなっています。

同梱の `cbc-registry-entry.json` を CbC の登録簿に足すと、
CbC の窓から盤面の生き死にが見えるようになります。

繋ぎ方の仕様そのものは CbC 側の `CONNECT.md` にあります。
自分のツールを繋ぎたいときは、そのファイルを Claude に読ませてください。

---

## 環境変数

| 変数 | 既定 | 用途 |
|---|---|---|
| `CSB_PORT` | 4788 | 待受ポート。埋まっていたら隣の空き番号へ自動で移ります |
| `CSB_HOME` | 利用者のフォルダ | 会話ログを探す起点 |
| `CSB_DATA_DIR` | アプリのフォルダ | `board.json` などの置き場所 |
| `CSB_NO_OPEN` | — | `1` にするとブラウザを開きません |

実際に待受けたポートは `port.txt` に書き出されます。
外から繋ぐものは、この番号を読んでください（決め打ちにしないこと）。

## 開発

```
node _qa/run-all.js      # 自己点検（終了コードで成否が分かる）
powershell -File build-dist.ps1   # 配布物を組む（中止ゲート4種つき）
```

アイコンは3案あります（`public/icons/app-a|b|c.svg`）。
採用案は `tools/make-icons-all.js` の `DEFAULT_VARIANT` で切り替えます。
